# Detecci-n-de-retinopat-a-diab-tica
Analizador de enrojecimiento ocular a partir de fotos externas. Segmenta la esclerótica, detecta venas/rojeces con HSV, calcula porcentaje de enrojecimiento y clasifica nivel (bajo a alto). Incluye interfaz gráfica, guarda máscaras y CSV. No diagnostica diabetes ni retinopatía (requiere retinografía). Uso orientativo para irritación/cansancio
